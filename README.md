## 🌟 Overview

**AuditionDance Web** brings back the classic competitive Korean rhythm dance experience directly to modern web browsers. Players synchronize arrow key combinations to the beat of high-energy tracks and execute moves by hitting the Spacebar on the critical 4th beat pulse bar.

---

## 🎮 Gameplay & Mechanics

- **Arrow Key Chain Input**: Execute sequence prompts (Up, Down, Left, Right) that increase in difficulty (Level 1 through Level 9 & Crazy Chains).
- **Rhythm Pulse Bar**: Hit Spacebar with pinpoint precision on the glowing beat node.
- **Scoring & Combo Hierarchy**:
  - **PERFECT**: Maximum combo multiplier and spotlight stage camera effects.
  - **GREAT / COOL / BAD**: Graded timing windows with degrading multipliers.
  - **MISS**: Resets input chain back to Level 1.
- **Audio-Visual Feedback**: Dynamic background beat pulses, glow particle trails, and reactive stage lights.

## 🚀 How to Play

Open index.html in any web browser:

`ash
git clone https://github.com/Sciclox/AuditionDanceWeb.git
cd AuditionDanceWeb
start index.html
`

### Controls
| Key | Action |
| --- | --- |
| ↑ ↓ ← → or 8 2 4 6 | Directional Chain Input |
| Spacebar or 5 (Numpad) | Beat Strike (Hit on the 4th Beat) |
| Tab | Toggle audio tracks |
